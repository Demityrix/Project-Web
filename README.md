# ArtVerse / Online Art Marketplace — PHP + MySQL Version

เวอร์ชันนี้ปรับจาก HTML/CSS/JS เดิมให้ระบบหลักเชื่อมกับฐานข้อมูล MySQL ผ่าน PHP API แล้ว เหมาะสำหรับรันด้วย XAMPP และใช้เป็น Prototype โครงงานแพลตฟอร์มขายผลงานศิลปะออนไลน์

## วิธีติดตั้ง

1. แตกไฟล์ zip ไปไว้ในโฟลเดอร์ XAMPP เช่น
   `C:\xampp\htdocs\art_marketplace_php`
2. เปิด XAMPP แล้ว Start `Apache` และ `MySQL`
3. เปิดโปรแกรมจัดการฐานข้อมูลแบบ Desktop เช่น **MySQL Workbench**, **DBeaver** หรือ **SQL Developer ที่ตั้งค่าไดรเวอร์ MySQL แล้ว**
4. สร้าง Connection โดยใช้ค่าตัวอย่าง
   - Host: `127.0.0.1`
   - Port: `3306`
   - Username: `root`
   - Password: เว้นว่าง หากใช้ค่าเริ่มต้นของ XAMPP
5. เปิดไฟล์ `database.sql` ในโปรแกรม แล้วกด Execute/Run ทั้งไฟล์
   - ไฟล์นี้จะสร้างฐานข้อมูล `art_marketplace`
   - มี `DROP TABLE IF EXISTS` เพื่อรีเซ็ตตารางเดิมและสร้างใหม่
6. Refresh โครงสร้างฐานข้อมูล แล้วตรวจสอบ Schema `art_marketplace` และตารางต่าง ๆ
7. เปิดเว็บ
   `http://localhost/art_marketplace_php/index.html`

### เหตุผลที่แนะนำโปรแกรม Desktop

- ทำงานและเปิดดูข้อมูลได้รวดเร็วกว่าเครื่องมือที่ทำงานผ่าน Browser
- ลดภาระการเปิดหลายหน้าเว็บและจัดการ Query ได้สะดวกกว่า
- แสดงโครงสร้างฐานข้อมูลชัดเจน เช่น Table, View, Trigger, Procedure, Index และ Relationship
- เขียน บันทึก และเรียกใช้ SQL Script ซ้ำได้ง่าย
- ดูผลลัพธ์ ตารางข้อมูล และแผนการทำงานของ Query ได้เป็นระเบียบ

> หมายเหตุ: ตัวเว็บยังเชื่อมต่อ **MySQL ผ่าน PHP PDO** เหมือนเดิม การเปลี่ยนเครื่องมือเป็น Desktop มีผลเฉพาะวิธีนำเข้า ตรวจสอบ และจัดการฐานข้อมูลเท่านั้น

ถ้า MySQL ของเครื่องตั้งรหัสผ่านไว้ ให้แก้ไฟล์ `api/config.php`

```php
const DB_HOST = 'localhost';
const DB_NAME = 'art_marketplace';
const DB_USER = 'root';
const DB_PASS = '';
```

## ระบบที่เชื่อม SQL แล้ว

### ผู้ใช้ / สมัครสมาชิก / Login

- สมัครสมาชิกผู้ซื้อ
- สมัครสมาชิกศิลปินและสร้างคำขออนุมัติศิลปิน
- Login จากตาราง `users`
- แก้ไขโปรไฟล์ / เบอร์โทร / ที่อยู่จัดส่ง
- ยกเลิกบัญชีพร้อมเหตุผล

### ตลาดสินค้า / ผลงานศิลปะ

- โหลดผลงานจากตาราง `products`
- ค้นหา / filter จากข้อมูลที่โหลดจาก MySQL
- ดูรายละเอียดผลงาน
- ดูโปรไฟล์ศิลปิน
- ศิลปินเพิ่มผลงานใหม่ลง SQL
- Admin อนุมัติ/ซ่อน/เผยแพร่ผลงาน

### ตะกร้าและ Wishlist

- ตะกร้าบันทึกในตาราง `cart_items` ตาม user
- Wishlist บันทึกในตาราง `wishlist_items` ตาม user
- เพิ่ม/ลบ/ปรับจำนวนสินค้าในตะกร้าเชื่อม SQL

### ซื้อผลงานด้วย Coin

- ซื้อทันทีจากหน้ารายละเอียดสินค้า
- Checkout จากตะกร้า
- หักเหรียญผู้ซื้อจาก `users.coins`
- เพิ่มเหรียญให้ศิลปินหลังหักค่าธรรมเนียมแพลตฟอร์ม
- สร้างคำสั่งซื้อใน `orders`
- สร้างประวัติธุรกรรมใน `transactions`
- ลด stock และเพิ่ม sold ใน `products`
- ล้างตะกร้าหลัง checkout สำเร็จ

### Coin Wallet

- เติมเหรียญผ่านปุ่ม QR จำลอง
- อัปเดตยอดเหรียญใน `users`
- บันทึกประวัติใน `transactions`
- Admin ตั้งค่าอัตรา Coin และค่าธรรมเนียมแพลตฟอร์มใน `settings`

### Buyer Dashboard

- ดูคำสั่งซื้อของตัวเอง
- ดูประวัติ Coin
- ดู Wishlist
- แจ้งปัญหา/คืนสินค้า สร้างข้อมูลใน `disputes`
- อัปเดตสถานะ order เป็นมีข้อพิพาท

### Artist Dashboard

- แก้ไขโปรไฟล์ศิลปิน
- เพิ่มผลงานใหม่
- ดูผลงานและคำสั่งซื้อของตัวเอง
- ยืนยันคำสั่งซื้อและใส่เลขพัสดุ
- ขอถอนเงินจากเหรียญเป็นเงินบาท
- ระบบถอนเงินบันทึกใน `withdrawals`

### Admin Dashboard

- อนุมัติ/ปฏิเสธศิลปิน
- คัดกรอง/เผยแพร่/ซ่อนผลงาน
- อนุมัติ/ปฏิเสธคำขอถอนเงิน
- จัดการข้อพิพาท
- ลบรีวิวไม่เหมาะสม
- ตั้งค่า Coin และค่าธรรมเนียม

### Chat / Review

- ส่งข้อความบันทึกใน `messages`
- เพิ่มรีวิวบันทึกใน `reviews`
- อัปเดต rating และจำนวนรีวิวใน `products`

## ไฟล์ PHP API สำคัญ

- `api/config.php` — ตั้งค่าฐานข้อมูลและ helper
- `api/state.php` — รวมฟังก์ชันดึง state จาก MySQL
- `api/load.php` — โหลดข้อมูลจาก SQL เข้าเว็บ
- `api/action.php` — API สำหรับ action จริง เช่น login, register, topup, checkout, add_cart
- `api/save.php` — API สำรองสำหรับบันทึก collection ทั้งชุด

## หมายเหตุ

เว็บนี้ยังเป็น Prototype เพื่อส่งงาน/สาธิตระบบ ไม่ใช่ production จริง จึงยังเก็บ password เป็น plain text เพื่อความง่ายในการทดลอง ถ้าจะใช้จริงควรเปลี่ยนเป็น `password_hash()` / `password_verify()` และเพิ่ม session/auth ฝั่ง PHP

## สำหรับคนที่เคย Import ฐานข้อมูลเวอร์ชันก่อนแล้ว

แนะนำให้ Import `database.sql` ใหม่เพื่อรีเซ็ตฐานข้อมูลให้ครบที่สุด แต่ถ้าไม่อยากลบข้อมูลเดิม ให้ลองรัน `database_update_only.sql` ก่อน เพื่อเพิ่มตาราง `cart_items`, `wishlist_items` และคอลัมน์ `cancel_reason`

## การปรับหน้าเมนูและบัญชีล่าสุด

- ปุ่มสามขีดเปิดเมนูบัญชีแบบ Side Drawer จากด้านขวา โดยแสดงเมนูทั้งหมดในหน้าจอเดียว
- เมนูมีคำสั่งซื้อ การซื้อ การประมูล สมัครเป็นครีเอเตอร์ บัญชี ตั้งค่า ช่วยเหลือ และออกจากระบบ
- หน้า Buyer Dashboard ปรับเป็นหน้า “บัญชีของฉัน” พร้อมยอด Coin สถานะคำสั่งซื้อ เมนูลัด และรายการโปรด
- เพิ่มหน้าต่างเพิ่ม/แก้ไขที่อยู่จัดส่ง โดยบันทึกผ่าน `update_profile` ลงคอลัมน์ `users.address`
- ศิลปินไม่สามารถเลือกสถานะ แสดง/ไม่แสดง/ขายแล้วได้อีกต่อไป ผลงานใหม่จะเข้าสถานะ `pending` เพื่อให้ Admin ตรวจสอบอัตโนมัติ
