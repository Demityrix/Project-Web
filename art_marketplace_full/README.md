# ArtVerse - Online Art Marketplace Prototype

โปรเจคเว็บต้นแบบสำหรับโครงงาน **แพลตฟอร์มขายผลงานศิลปะออนไลน์** แนว Friendii.art ใช้ HTML, CSS และ JavaScript แบบ Static Frontend

## วิธีเปิดใช้งาน

1. แตกไฟล์ ZIP
2. เปิด `index.html` ได้เลย
3. แนะนำให้เปิดด้วย VS Code + Live Server เพื่อให้การเปลี่ยนหน้าและ path รูปทำงานเสถียรที่สุด

## ไฟล์หลัก

- `index.html` หน้าแรก / ตลาดผลงาน / ค้นหาและกรองสินค้า
- `product.html` หน้ารายละเอียดผลงาน / รีวิว / โปรไฟล์ศิลปิน / เพิ่มตะกร้า / ซื้อด้วยเหรียญ
- `login.html` เข้าสู่ระบบและสมัครสมาชิก
- `cart.html` ตะกร้าสินค้าและชำระเงินด้วย Coin
- `wallet.html` Coin Wallet / เติมเหรียญผ่าน QR Code จำลอง / ประวัติธุรกรรม
- `buyer-dashboard.html` แดชบอร์ดผู้ซื้อ / ข้อมูลส่วนตัว / คำสั่งซื้อ / Wishlist / ประวัติ Coin
- `artist-dashboard.html` แดชบอร์ดศิลปิน / โปรไฟล์ / อัปโหลดผลงาน / คำสั่งซื้อ / ถอนเงิน
- `admin-dashboard.html` แดชบอร์ดผู้ดูแล / อนุมัติศิลปิน / คัดกรองผลงาน / จัดการเหรียญ / ถอนเงิน / ข้อพิพาท / รายงาน
- `chat.html` ระบบแชทจำลอง
- `css/style.css` ไฟล์ตกแต่งหน้าเว็บ
- `js/data.js` ข้อมูลตัวอย่างสินค้า ผู้ใช้ คำสั่งซื้อ รีวิว ธุรกรรม
- `js/app.js` Logic การทำงานของระบบจำลอง
- `assets/` รูปภาพผลงาน 16 รูป

## สิ่งที่ครอบคลุมตามขอบเขตโครงงาน

### ผู้ใช้ทั่วไป
- ดูหน้าเว็บไซต์และผลงานโดยไม่ต้องลงทะเบียน
- ค้นหาตามหมวดหมู่ ประเภท ศิลปิน และราคา
- ดูรายละเอียดผลงาน ราคา ข้อมูลศิลปิน คะแนนและรีวิว
- สมัครสมาชิกเพื่อซื้อขายและใช้งาน Coin

### ผู้ซื้อ
- Login/Register
- แก้ไขข้อมูลส่วนตัวและที่อยู่จัดส่ง
- ยกเลิกบัญชีพร้อมเหตุผล
- เติมเหรียญผ่าน QR Code จำลอง
- ตรวจสอบ Coin Wallet
- Wishlist / Cart / Checkout ด้วย Coin
- ดูคำสั่งซื้อ สถานะจัดส่ง ประวัติ Coin และใบเสร็จจำลอง
- รีวิวสินค้า และแจ้งปัญหา/คืนสินค้า
- แชทกับศิลปิน

### ศิลปิน
- สมัครเป็นศิลปินและรออนุมัติ
- แก้ไขโปรไฟล์ศิลปิน
- อัปโหลดผลงาน กำหนดราคาเป็น Coin หมวดหมู่ ประเภท สถานะ
- ดูคำสั่งซื้อและยืนยันเลขพัสดุ
- ดูยอด Coin รายงานยอดขาย รีวิว และถอนเงินเป็นเงินบาท
- แชทกับผู้ซื้อ

### Admin
- เข้าสู่ Dashboard
- อนุมัติ/ปฏิเสธศิลปิน
- ควบคุมการเผยแพร่ผลงาน
- จัดการอัตราแลกเปลี่ยน Coin และค่าธรรมเนียมแพลตฟอร์ม
- อนุมัติ/ปฏิเสธรายการถอนเงิน
- ดูแลข้อพิพาท/คืนสินค้า
- ลบรีวิวไม่เหมาะสม
- ดูรายงานภาพรวม

## หมายเหตุ

โปรเจคนี้เป็น Frontend Prototype จึงใช้ `localStorage` เก็บข้อมูลจำลองในเครื่องผู้ใช้ ไม่ได้เชื่อมต่อฐานข้อมูลจริงหรือ Payment Gateway จริง
